# Runtime 26.10 + Transfer-Link Spike Implementation Plan (Piece 0)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the extension load again on the current Claude Desktop (Electron 44.4.3) by moving to `@actual-app/api` 26.10.0 and its N-API `better-sqlite3` 13, rebuild the bundle verification for N-API, and run the spike that decides how Piece A links two existing transactions into a transfer.

**Architecture:** No new runtime modules. `scripts/electron-target.ts` swaps its prebuild/ABI helpers for an N-API classifier over `nm` output; `scripts/bundle.ts` steps 5–6 use it. Piece A (reconciliation tools) gets its own plan once the spike results exist.

**Tech Stack:** TypeScript, Vitest, `tsx`, `@actual-app/api` 26.10.0, `better-sqlite3` 13 (N-API), Docker (ephemeral `actualbudget/actual-server:26.10.0`), `@anthropic-ai/mcpb`.

**Spec:** `docs/superpowers/specs/2026-10-08-actual-26-10-reconciliation-design.md` (sections *Piece 0* and *Spike results*).

## Review Focus

- **`better-sqlite3` 13 ships more than one `.node` file** (per-platform prebuilds inside the package) → the bundle check must classify every `.node` it finds and accept only if all are N-API; pinned by the "varios binarios" test in Task 2.
- **No `.node` at all** in the staged `better-sqlite3` (install produced nothing) → bundle aborts with a Spanish message, never packs; pinned in Task 2.
- **An old ABI-specific addon sneaks in** (lockfile still resolving `better-sqlite3` 12 through some other path) → classifier reports `abi` and bundle aborts; pinned in Task 2, plus `npm ls better-sqlite3` check in Task 1.
- **Claude Desktop not installed on the build machine** → bundling still succeeds (Electron version is only logged now); pinned by removing `resolveElectronTarget` and its throwing path in Task 2/3.
- **`better-sqlite3` 13 moved its binary** away from `build/Release/better_sqlite3.node` → the server's startup `native-check` would silently stop checking; Task 1 verifies the real path and updates `nativeAddonPath` + its test if it moved.

Replace the whole file with:

```ts
// El servidor de una extensión .mcpb no corre bajo Node: Claude Desktop lo arranca como
// UtilityProcess de su propio Electron. Hasta better-sqlite3 12 eso obligaba a compilar el
// módulo nativo contra el ABI exacto de ese Electron y a reempaquetar con cada subida mayor.
// better-sqlite3 13 es N-API: un mismo binario carga en cualquier Node o Electron. Aquí vive
// la lógica pura de "¿el binario que viaja es N-API?", leída de la salida de `nm -gU`.

/** Info.plist del Electron Framework de la app instalada, tal y como lo lee `plutil -p`. */
export const CLAUDE_ELECTRON_PLIST =
  '/Applications/Claude.app/Contents/Frameworks/Electron Framework.framework/Versions/A/Resources/Info.plist';

/** Versión de Electron de Claude Desktop. Solo informativa: el bundle ya no depende de ella. */
export function parseElectronVersion(plutilOutput: string): string | null {
  const match = plutilOutput.match(/"CFBundleVersion"\s*=>\s*"(\d+\.\d+\.\d+)"/);
  return match ? match[1] : null;
}

export type AddonKind = { kind: 'napi' } | { kind: 'abi'; abi: number } | { kind: 'unknown' };

/** Clasifica un .node por sus símbolos exportados (`nm -gU`). */
export function classifyAddon(nmOutput: string): AddonKind {
  if (/\b_?napi_register_module_v1\b/.test(nmOutput)) return { kind: 'napi' };
  const abi = nmOutput.match(/\b_?node_register_module_v(\d+)\b/);
  if (abi) return { kind: 'abi', abi: Number(abi[1]) };
  return { kind: 'unknown' };
}

/** Todos los binarios que viajan deben ser N-API; si no hay ninguno, el bundle no sirve. */
export function checkAddons(addons: { file: string; nm: string }[]): { ok: boolean; detail: string } {
  if (addons.length === 0) {
    return { ok: false, detail: 'no se encontró ningún binario nativo de better-sqlite3' };
  }
  for (const { file, nm } of addons) {
    const kind = classifyAddon(nm);
    if (kind.kind === 'abi') {
      return {
        ok: false,
        detail: `${file} está atado a NODE_MODULE_VERSION ${kind.abi}: no es N-API y fallará con otro Electron`,
      };
    }
    if (kind.kind === 'unknown') {
      return { ok: false, detail: `${file} no exporta ningún símbolo de registro reconocible` };
    }
  }
  return { ok: true, detail: `${addons.length} binario(s) nativo(s) N-API` };
}
```

```ts
// Spike (Piece 0.3 of the 2026-10-08 reconciliation spec). THROWAWAY: it answers questions,
// it is not product code. Runs against the ephemeral 26.10.0 server ONLY:
//
//   docker compose -f test/integration/docker-compose.actual.yml up -d
//   npx tsx scripts/verify/spike-link-transfer.ts
//
// Not under vitest: NODE_ENV=test makes @actual-app/api take an eager resync path that hangs
// (see scripts/demo/reset-check.ts). Questions answered, all printed in RESULT=:
//   A. transfer + merge: set X's payee to B's transfer payee (Actual creates X' in B), then
//      mergeTransactions([X', Y]). Which row survives? Is imported_id kept? Linked both ways?
//   B. direct link: write transfer_id on X and Y, then set the transfer payees.
//   C. getAccountBalance(id, cutoff): does cutoff include transactions dated ON cutoff?
//   D. after shutdown, a second client downloading the budget sees the same state.
import * as fs from 'node:fs';
import * as os from 'node:os';
import * as path from 'node:path';
import * as api from '@actual-app/api';

const URL = process.env.ACTUAL_SERVER_URL ?? 'http://localhost:5006';
const PASSWORD = process.env.ACTUAL_SERVER_PASSWORD ?? 'test-pass';
if (!/localhost|127\.0\.0\.1/.test(URL)) throw new Error(`Spike solo contra el servidor efímero local, no ${URL}`);

const DATE = '2026-09-15';

async function rows(filter: Record<string, unknown>) {
  const { data } = await api.runQuery(
    api.q('transactions').filter(filter).options({ splits: 'all' }).select(['*']),
  );
  return data as any[];
}

async function transferPayeeOf(accountId: string): Promise<string> {
  const payees = await api.getPayees();
  const p = payees.find((x: any) => x.transfer_acct === accountId);
  if (!p) throw new Error(`sin payee de transferencia para ${accountId}`);
  return p.id;
}

/** Two on-budget accounts, one imported transaction each, opposite amounts, same date. */
async function fixture(tag: string) {
  const a = await api.createAccount({ name: `${tag} A`, offbudget: false }, 0);
  const b = await api.createAccount({ name: `${tag} B`, offbudget: false }, 0);
  await api.importTransactions(a, [
    { date: DATE, amount: -10000, payee_name: 'Traspaso banco', imported_id: `${tag}-x` },
  ]);
  await api.importTransactions(b, [
    { date: DATE, amount: 10000, payee_name: 'Traspaso banco', imported_id: `${tag}-y` },
  ]);
  const [x] = await rows({ account: a });
  const [y] = await rows({ account: b });
  return { a, b, x, y };
}

function summary(r: any) {
  return r && {
    id: r.id, account: r.account, amount: r.amount, date: r.date,
    imported_id: r.imported_id ?? null, transfer_id: r.transfer_id ?? null,
    payee: r.payee ?? null, tombstone: r.tombstone ?? false,
  };
}

async function mechanismA() {
  const { a, b, x, y } = await fixture('SpikeA');
  await api.updateTransaction(x.id, { payee: await transferPayeeOf(b) });
  const inB = await rows({ account: b });
  const xPrime = inB.find((r) => r.id !== y.id);
  const mergeReturn = xPrime ? await api.mergeTransactions([xPrime.id, y.id]) : 'no X′ created';
  return {
    mergeReturn,
    afterX: summary((await rows({ id: x.id }))[0]),
    accountB: (await rows({ account: b })).map(summary),
    balanceA: await api.getAccountBalance(a),
    balanceB: await api.getAccountBalance(b),
  };
}

async function mechanismB() {
  const { a, b, x, y } = await fixture('SpikeB');
  let error: string | null = null;
  try {
    await api.updateTransaction(x.id, { transfer_id: y.id });
    await api.updateTransaction(y.id, { transfer_id: x.id });
    await api.updateTransaction(x.id, { payee: await transferPayeeOf(b) });
    await api.updateTransaction(y.id, { payee: await transferPayeeOf(a) });
  } catch (e) {
    error = (e as Error).message;
  }
  return {
    error,
    accountA: (await rows({ account: a })).map(summary),
    accountB: (await rows({ account: b })).map(summary),
    balanceA: await api.getAccountBalance(a),
    balanceB: await api.getAccountBalance(b),
  };
}

async function cutoffSemantics() {
  const acc = await api.createAccount({ name: 'SpikeCutoff', offbudget: false }, 0);
  await api.addTransactions(acc, [{ date: DATE, amount: 500 }]);
  return {
    cutoffSameDayLocalMidnight: await api.getAccountBalance(acc, new Date(`${DATE}T00:00:00`)),
    cutoffSameDayEndOfDay: await api.getAccountBalance(acc, new Date(`${DATE}T23:59:59`)),
    cutoffNextDay: await api.getAccountBalance(acc, new Date('2026-09-16T00:00:00')),
    noCutoff: await api.getAccountBalance(acc),
  };
}

async function run(): Promise<void> {
  const dir1 = fs.mkdtempSync(path.join(os.tmpdir(), 'spike-link-1-'));
  const dir2 = fs.mkdtempSync(path.join(os.tmpdir(), 'spike-link-2-'));
  const result: Record<string, unknown> = {};
  try {
    await api.init({ dataDir: dir1, serverURL: URL, password: PASSWORD });
    await api.runImport('SpikeLink', async () => {});
    const budgets = await api.getBudgets();
```
